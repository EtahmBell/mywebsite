# Website4Dog

A basic, responsive dog-themed website built with Next.js App Router and TypeScript.

## Run locally

Requires Node.js 20.9 or newer.

```sh
npm ci
npm run dev
```

Open http://localhost:3000.

## Checks and production

```sh
npm run lint
npm run build
npm start
```

Edit `src/app/page.tsx` for page content, `src/app/globals.css` for styling, and `src/app/layout.tsx` for metadata. The app has no external service dependencies or required environment variables.
